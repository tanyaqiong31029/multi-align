第一步 · 导入各版本文本

添加同一文本的 2–10 个语言版本（推荐 5–10 个）。可粘贴文本，或导入 txt / md / docx / SRT・VTT 字幕文件；选择一个版本作为基准语（其他语言均与它对齐）。

提示：至少需要 2 个版本的文本（推荐 5–10 个）

第二步 · 设置参数并自动对齐

算法将把每个版本与基准语逐一进行句句对齐，再合并为多语对照表。

版本概览

对齐参数

当各版本自然段数量一致时，逐段独立对齐，可显著提高准确率（推荐勾选）。
默认分号不切分句子；法律、新闻类文本可开启。
数字、日期、百分比在译文中通常保持一致，是对齐的强线索（跨语种有效）。
仅在兼容文种间生效（如中↔日共享汉字、西文之间共享词汇），跨文种自动禁用。
当两个版本都以字幕文件（SRT/VTT）导入时启用：台词时间重合度是最可靠的对齐信号，一般保持 80。
Gale-Church 长度方差：同文种 6.8、跨文种 9.0，一般保持默认即可。
算法说明 ▾

采用 Gale & Church (1993) 长度统计对齐模型：以句长差显著性的负对数概率为代价， 动态规划求解最优的 1-1 / 1-2 / 2-1 / 2-2 / 1-0 / 0-1 句对组合；跨文种时按“汉字≈2.3 个西文字符”加权。 多版本结果通过并查集（连通分量）合并为翻译单元。

使用指南

本工具在浏览器中完成全部计算，文本不会上传到任何服务器。建议使用 Chrome / Edge / Safari 16.4+ 等现代浏览器。

一、准备文本

  • 准备同一文本的多个语言版本（2–10 个）。译本的章节、段落结构应与原文基本一致。
  • 可接受的输入：直接粘贴文本；.txt / .md 文件（自动识别 UTF-8 / GBK / Big5 编码）；.docx 文件（自动提取正文，保留段落）。
  • 段落格式建议：各版本用空行分隔自然段。若各版本段落数一致，工具会自动启用“段落锚定”，逐段对齐，准确率最高。
  • “一句一行”的文本也可以直接使用——此时每行即一个句子。

三、选择基准语

基准语（pivot）是所有其他版本的对齐参照，通常是原文。例如：中文原文 + 英、日、法、德、西 5 个译本，则以中文为基准语，5 个译本分别与中文对齐后合并成 6 列对照表。

二、字幕对齐（SRT / VTT）

  • 把同一视频的两个语言字幕文件（如中文 .srt + 英文 .srt）分别导入为两个版本，工具会按台词时间轴自动对齐——时间重合度是最可靠的锚点。
  • 粘贴字幕文本也能被自动识别（含 --> 时间轴即视为字幕）；解析时自动清除 <i> 等标签。
  • 对齐后可导出多语合并字幕（每条台词多行对照，播放器可直接挂载）或各语言单语字幕的 ZIP；时间轴取自基准语。
  • 字幕版本建议整部或按章节成对导入；两种字幕若时间轴偏移较大（不同帧率），可在第二步调低「时间轴锚点权重」后重新对齐。

四、理解对齐结果

  • 每一行是一个翻译单元（TU），各列为对应语言的句子。
  • 某版本一句对基准语两句时，两句会自动拼接放入同一单元格（1-2 对齐）。
  • 置信度标记：🟢 高（典型 1-1 对齐）、🟡 中（含 1-2 / 2-1 合并）、🔴 低（未匹配或跨句合并）、🟣 紫（人工修改过）。建议优先审校红色行。
  • 单元格为空表示该语言在此处没有对应内容（漏译或原文独有）。

五、审校操作

  • 编辑文字：单击单元格直接输入；Tab 跳到下一格，Enter 换行。
  • 行操作：点选行号所在行后，使用工具栏「合并下行 / 插行 / 删行 / 上移下移」。
  • 单元格拆分：选中单元格后点击「✂ 拆分」，按句子切成两行（仅该列，其余列留空，便于补充）。
  • 锁定：确认无误的行请锁定，导出时可只导出已锁定行。
  • 搜索替换：Ctrl+F，可限定某一列，支持全部替换（可撤销）。
  • 撤销 / 重做：Ctrl+Z / Ctrl+Y。

六、导出

  • TMX 多语言版：符合 TMX 1.4 规范，一个 <tu> 内含所有语言的 <tuv>；OmegaT、Trados、memoQ 等均支持。
  • 两两 TMX（ZIP）：基准语 × 每个译本各一个双语 TMX 文件，方便分发给不同语向的团队。
  • Excel / CSV：行号 + 各版本列；CSV 带 BOM，Excel 打开不乱码。
  • TXT：制表符分隔的平行文本，可直接用于 MT 训练流水线。

七、常见问题

对齐错了怎么办？

先用「只看低置信度」筛出可疑行，用合并 / 拆分 / 清空手工修正；长文本建议确保各版本段落数一致以启用段落锚定。

为什么某个版本整列都是空？

通常是该版本与基准语长度比例异常（如误传了别的文档），或句子数差异过大。返回第一步检查文本与语言设置。

支持多少文本量？

常规书籍章节（数千句）可流畅处理；超长文本会自动滑窗分块。建议按章节分批处理。

数据安全吗？

纯前端工具，无任何网络请求（文件图标素材亦为内联 SVG）。工程可通过「保存工程」导出 JSON 备份，浏览器本地另有自动保存。

💡 小技巧：审校完一批行就锁定一批；导出时勾选「仅导出已锁定行」，可以分批产出高质量语料。

关于本工具

「多语对齐工作台 MultiAlign」是一个参考 tmxmall 等在线对齐平台交互流程打造的纯前端多语平行语料构建工具，面向翻译研究者、本地化团队与 MT 语料工程师。

技术架构

  • 零依赖原生 HTML / CSS / JavaScript，双击 index.html 即可离线使用。
  • 分句引擎：多语规则分句（缩写库、小数与引号处理、CJK 标点规则）。
  • 对齐引擎：Gale & Church (1993) 统计句对齐 + 数字锚点 + 兼容文种词汇相似度 + 段落锚定 + 滑窗分块。
  • 多版本合并：基准语枢纽对齐 + 并查集连通分量 → 翻译单元。
  • 导出器：内置 ZIP 读取（docx 导入）与 ZIP / XLSX 写入（零第三方库）。
